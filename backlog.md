# Backlog

The canonical tasks are the files in [`backlog/`](backlog/). Use that directory's
complete file listing or the ycc backlog tools to discover work and read current
status, dependencies, acceptance criteria, and work logs.

There is deliberately no copied status table here: the previous snapshot omitted
newer tasks and drifted from their frontmatter. Task creation and status changes
belong in the backlog tools, not in a second manually maintained index.

- `proposed` work is an idea, not accepted scope.
- `todo` / `in_progress` work is actionable only when dependencies are done.
- `blocked` / `in_review` tasks retain those gates even when dependencies are done.
- Completed tasks and git history retain shipped decisions and evidence.

A historical plan, benchmark runner, or old approval does not override a task's
current blocker or a data-retention hold.
